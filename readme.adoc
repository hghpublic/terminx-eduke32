== Building EDuke32 on Linux

https://wiki.eduke32.com/wiki/Building_EDuke32_on_Linux

make::
+
[source, shell]
----
❯ make > dev/logs/make.log 2>&1
----

disable pretty output to reduce log size in `Common.mak`::
+
----
##### Makefile meta-settings

#PRETTY_OUTPUT := 1
PRETTY_OUTPUT := 0
----

cmake::
+
[source, shell]
----
❯ ./build.sh > dev/logs/cmake.log 2>&1
----
